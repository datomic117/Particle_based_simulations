Data Structures
Here are the data structures with brief descriptions:
 CAngleStruct to store indices of particles in an angle i-j-k
 CBondStruct to store indices of bonded particles i-j
 CCelllistA cell-linked-list: the box is divided into cells at least as large as the interaction range, so all neighbors of a particle are found in its own cell and the 26 surrounding ones
 CDeltaRA 3D vector stored together with its square length. Used for connecting vectors and accumulated displacements, where the square length is needed anyway for comparisons against a cut-off distance
 CDihedralStruct to store indices of particles in a dihedral i-j-k-l
 CIndex3DStruct to store i, j, k indices of a 3D grid
 CNbrlistThe (Verlet) neighbor list: all particle pairs closer than r_cut + r_shell when the list was last built
 CPairOne entry of the neighbor list: a pair of particles within interaction range. Only the indices are stored; the connecting vector is computed from the current positions in the force loop
 CParametersAll run settings in one struct, set by set_parameters. There are no input files: changing a run means editing setparameters.c and recompiling
 CVec3DA 3D vector
 CVectorsAll per-particle data of the simulation, stored as parallel arrays: element i of each array belongs to particle i. Also carries the molecular topology (bonds, angles, dihedrals) and the accumulated pressure contributions of the current time step
