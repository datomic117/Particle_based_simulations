Build the neighbor list: all pairs closer than r_cut + r_shell.

A cell-linked-list is built first, so only particles in neighboring cells have to be considered as candidates; this makes the cost of the build grow linearly with the number of particles instead of quadratically.

Parameters
p_parametersused members: r_cut, r_shell, factor_12_nb, factor_13_nb, factor_14_nb

p_nbrlistthe neighbor list to (re)build

◆ update_nbrlist()

int update_nbrlist ( struct Parameters *  p_parameters,
struct Vectors *  p_vectors,
struct Nbrlist *  p_nbrlist 
)

Rebuild the neighbor list when it can no longer be trusted.

The list contains all pairs that were closer than r_cut + r_shell when it was built. It remains valid as long as no particle has moved further than r_shell/2 since then (two particles approaching each other can close the gap from both sides); once one has, the list is rebuilt.

Parameters
p_parametersused members: r_shell
p_vectorsused members: r
p_nbrlistused members: dr (per-particle displacement since the last build)
Returns
int 1 if the list was rebuilt, 0 if it was still valid.
