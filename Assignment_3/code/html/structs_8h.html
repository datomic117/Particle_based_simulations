typedef struct Vec3D Vec3D

A 3D vector.

All positions, velocities and forces are stored as arrays of Vec3D. The v3_* helper functions below implement the usual vector operations; they are 'static inline' so the compiler expands them in place and they cost the same as writing the component arithmetic out by hand.
