Detailed Description

The (Verlet) neighbor list: all particle pairs closer than r_cut + r_shell when the list was last built.

The extra margin r_shell allows the same list to be reused for many steps. The accumulated displacement of each particle since the last build is tracked in dr; once any particle has moved more than r_shell/2 the list is no longer guaranteed to contain all pairs within r_cut and is rebuilt (see update_nbrlist).

The head12/pairs12 arrays (and 13, 14 alike) store which particle pairs are 1-2 (directly bonded), 1-3 and 1-4 connected, in compact form: the bonded partners of particle i are pairs12[head12[i]] up to pairs12[head12[i+1]]. They are only built when the corresponding scaling factor differs from one (see Parameters::factor_12_nb).
