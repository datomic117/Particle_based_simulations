void build_nbrlist ( struct Parameters *  p_parameters,
struct Vectors *  p_vectors,
struct Nbrlist *  p_nbrlist 
)

Build the neighbor list: all pairs closer than r_cut + r_shell, ordered by (i, j).

A cell-linked-list is built first, so only particles in neighboring cells have to be considered as candidates; this makes the cost of the build grow linearly with the number of particles instead of quadratically. The final ordering allows update_nbrlist to carry the tangential contact histories across a rebuild in a single walk over the old and the new list.

Parameters
p_parametersused members: r_cut, r_shell, L
p_vectorsused members: r
p_nbrlistthe neighbor list to (re)build

◆ update_nbrlist()

int update_nbrlist ( struct Parameters *  p_parameters,
struct Vectors *  p_vectors,
struct Nbrlist *  p_nbrlist 
)

Keep the neighbor list valid: rebuild it when needed, update it otherwise.

The list contains all pairs that were closer than r_cut + r_shell when it was built, and stops being trustworthy once a particle has moved more than r_shell/2 since then; the list is then rebuilt, and the tangential contact histories are carried over to the new list. Otherwise the stored connecting vectors are updated with the displacements of the last time step.

Parameters
p_parametersused members: r_shell
p_vectorsused members: dr
p_nbrlistused members: nbr, tij, dr, nbr_prev, tij_prev
Returns
int 1 if the list was rebuilt, 0 if it was only updated.
