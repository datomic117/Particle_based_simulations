Detailed Description

The (Verlet) neighbor list: all particle pairs closer than r_cut + r_shell when the list was last built, kept sorted by (i, j).

The extra margin r_shell allows the same list to be reused for many steps; it is rebuilt once a particle has moved more than r_shell/2 (see update_nbrlist). The sorting matters here: it is what lets the tangential contact history tij be carried across a rebuild in a single walk over the old and the new list.

◆ tij

struct DeltaR* tij

Tangential displacement of the contact between the two particles of pair k, or zero while they are not touching. It lives here, beside the pair, so that a contact keeps its history for as long as the pair stays in the list. Only when the list is rebuilt does the history have to be carried over, which update_nbrlist does.
