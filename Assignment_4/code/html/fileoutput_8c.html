void record_trajectories_xyz ( int  reset,
struct Parameters *  p_parameters,
struct Vectors *  p_vectors

Output the particle positions to an xyz file, for visualization in tools such as OVITO. Each line holds a particle name, the position, the radius and the speed, in SI units. The second line of a frame follows the extended-XYZ convention: the box (Lattice), the column names (Properties) and the time (Time, from Vectors::time), so OVITO maps the columns itself.

Parameters
reset1: write new file or overwrite existing file, 0: append data
p_parametersused members: filename_xyz
p_vectorsused members: time, r, radius, v
