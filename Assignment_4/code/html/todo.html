Task D2: count the particles still in the silo, those whose centre is above the plate (r.z > z_silo). main prints the count as the last column of its table, which then gives N(t), the number of particles in the silo against time.
Global cylinder_wall (struct Parameters *p_parameters, double radius, struct Vec3D *r, struct DeltaR *riw, struct Vec3D *vw)
Task C1: the cylindrical silo wall. Its axis is the vertical line through (0.5*L.x, 0.5*L.y). With rc the distance of the particle centre to the axis, the particle overlaps the wall when rc > R_cyl - radius. The closest wall point is then at distance R_cyl from the axis, in the same direction as the particle, so riw is the horizontal vector (rc - R_cyl) * (dx, dy, 0) / rc, with (dx, dy) the horizontal offset of the centre from the axis, and riw.sq its square length. The wall is static: vw = 0. The cylinder only exists above the plate: return false for a particle with r->z < z_silo, so the discharged material can spread over the floor below. bottom_wall, at the top of walls.c, is an example of the contract.
Global initialise_collision (struct Parameters *p_parameters, struct Vectors *p_vectors)
Task A1 and A2: set up the test collision. num_part is 1 or 2 (NUM_TEST in setparameters.c) and gravity is off. Give the particles equal radii R_min and the matching mass (density * 4/3 pi R^3), and zero angular velocity. One particle (A1): place it just above the bottom wall, at height 1.05 * R in the middle of the box, moving straight down with speed v_impact. Two particles (A2): place them on a line along x in the middle of the box, centres 2 * 1.05 * R apart, moving towards each other with speed v_impact each. Until this is done the lattice of the starting code is used, at rest.
Global initialise_positions_silo (struct Parameters *p_parameters, struct Vectors *p_vectors)
Task C3: fill the silo. Place the particles on a loose cubic lattice clipped to the cylinder, layer by layer from the bottom plate up:
  • spacing dl = 2.2 * R_max, so no two particles start in contact;
  • keep a site only when its distance to the axis (0.5*L.x, 0.5*L.y) is below R_cyl - 1.1 * R_max, so no particle starts in the cylinder wall;
  • the first layer at height z_silo + 1.1 * R_max, just above the closed plate;
  • shift each coordinate of each site by a random amount of at most 0.04 * R_max (use generate_uniform_random), so the bottom layer does not keep the square order of the lattice. For 7500 particles the lattice is about 100 mm high, against about 58 mm for the settled fill; the box has room for it. The fill then settles under gravity on the closed plate until t_open; no separate randomisation stage is needed. Until this is done the lattice of the starting code is used.
Global silo_bottom_wall (struct Parameters *p_parameters, double radius, struct Vec3D *r, struct DeltaR *riw, struct Vec3D *vw)
Task C2: the edge of the hole. Here the orifice is open and the particle centre is over the hole (rc < R_orifice), within one radius of the plane of the plate. Such a particle can still touch the plate, at the edge of the hole. Work out which point of the plate is then closest to the centre, and return true when the particle overlaps it, with riw the vector from that point to the centre (riw.sq its square length) and vw = 0, as for every wall. Mind the particle that sits exactly on the axis. Until this is done, a particle over the hole never touches the plate: the silo discharges, but through a hole whose edge the particles do not feel.
Global update_parameters (struct Parameters *p_parameters, double time)

Task B: tilt the bed by rotating gravity. Before t_tilt the slope angle is zero (the bed settles); from t_tilt on it grows as theta = tilt_rate * (time - t_tilt). Store theta in p_parameters->slope_angle and set p_parameters->g = GRAVITY * (sin(theta), 0, -cos(theta)).

Task C2: open the orifice at t_open: set p_parameters->orifice_open to 1 once time >= t_open. Your silo_bottom_wall reads this flag.
