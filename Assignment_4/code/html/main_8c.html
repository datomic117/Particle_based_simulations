PBS Assignment 4: Silo Discharge (DEM) - Required Code Extensions

The A4 notebook is the assignment text. Every piece of code you have to write already exists as a function that compiles and is called from the right place; the todo marker inside it says what to fill in (see the todo list of the Doxygen documentation, html/index.html). Choose the run with the macro RUN at the top of setparameters.c, or on the command line:

gcc -O3 -DRUN=1 *.c -o dem -lm Part A, a test collision (RUN_COLLISION) gcc -O3 -DRUN=2 *.c -o dem -lm Part B, a bed tilted by rotating gravity (RUN_SLOPE) gcc -O3 -DRUN=3 *.c -o dem -lm Parts C and D, the silo (RUN_SILO)

A. VERIFICATION, restitution (initialise.c: initialise_collision) One particle hits the bottom wall (A1), or two particles collide head-on (A2), without gravity. The table printed every step gives the kinetic energy before and after the collision, and with it the restitution coefficient. B. SLOPE STABILITY (setparameters.c: update_parameters) The bed of the starting code settles, then gravity rotates slowly; find the angle at which the bed starts to move. C. BUILDING THE SILO (walls.c: cylinder_wall, silo_bottom_wall; initialise.c: initialise_positions_silo; setparameters.c: update_parameters) A cylindrical wall, a bottom plate with a closable orifice, a fill that settles on the closed plate. D. DISCHARGE AND THE BEVERLOO LAW (walls.c: count_in_silo) The orifice opens at t_open; the number of particles left in the silo, printed as the last column of the table, gives the discharge rate.

The starting code simulates spherical particles between a floor and a ceiling; the assignment builds it out to the discharge of a cylindrical silo, validated against the Beverloo law. Each time step first applies the time-dependent part of the run (update_parameters: the rotation of gravity in Part B, the opening of the orifice in Part D).

The table printed to the screen has the columns step, time, coordination number Z, potential and kinetic energy, their sum, and N_silo, the number of particles in the silo (in Parts A and B, which have no silo, that is simply every particle). Redirect it to a file: ./dem > run.dat
