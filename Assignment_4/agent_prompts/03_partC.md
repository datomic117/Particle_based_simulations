## Steps
1. 2. 3. C2 geometry (derive and verify, do not just trust this hint): for a centre over the open hole (rc < R_orifice) within one radius of the plate plane, the plate is the half-plane z = z_silo for rc' >= R_orifice, so the closest point is on the rim circle, in the same azimuth: P = (axis + R_orifice * e_r, z_silo), and riw = r - P = ((rc - R_orifice) e_r, z - z_silo); overlap if |riw| < radius; on the axis (rc = 0) every rim point is equally close: pick any direction (no division by zero, no NaN). Write the argument as a formula plus one sentence/sketch in the notebook.
4. **Prove C2 and C1 numerically** with a standalone harness in `code/tests/wall_check.c` (a subdirectory, so `gcc *.c` is unaffected; it links the real `walls.c`): many random points near the rim and the axis; compare `riw`, the overlap flag and `riw.sq` with a brute-force closest point on a finely sampled rim circle (max deviation ~ 1e-6 of a radius); check continuity at rc = R_orifice with the flat plate branch, the on-axis case and both orientations (orifice closed/open). Write its output to `data/C_wall_check.txt` and cite it in the notebook as how you convinced yourself. Also state what a particle at the edge does without the edge code (it does not feel the rim: a centre inside R_orifice falls freely, so the effective orifice is larger by about one radius and the discharge is too fast); do not run extra simulations for this unless cheap.
5. Short smoke run first (RUN=3, stop after a few hundred ms or use a temporary shorter copy of the build in `runs/`; do not change defaults): no NaN, all particles inside the cylinder, N_silo = 7500 at t = 0, fill settles. Then the production run: `-DRUN=3` (defaults) as `runs/D7`, in background (about 4 min, maybe 2-3x on this machine). Copy the table to `data/D7.dat`.
6. OVITO: `$PY -m pip install ovito` if missing. 7. Analysis: with `code/extract_frame.py` (made in Part B) save that frame as `data/C_frame_before_open.dat`. Cell 18 (code): settling figure, the phi / rho_b / Z printouts, the radial profile figure (core boundary marked); embed the OVITO PNG (`IPython.display.Image` or `plt.imread`, relative path).
